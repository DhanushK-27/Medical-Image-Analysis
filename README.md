Medical Image Processing & Analysis

Overview

A Python-based project focused on implementing fundamental image-processing algorithms for medical image enhancement and analysis. Using OpenCV and NumPy, the project explores noise reduction, contrast enhancement, thresholding, and edge detection techniques on medical image datasets. Pytest is used to automate functional testing and verify algorithm outputs.

Features

* Gaussian Filtering: Reduces noise and smooths image intensity variations.
* Median Filtering: Reduces impulse noise while often preserving edges.
* Histogram Equalization: Enhances global image contrast.
* CLAHE: Improves local contrast while limiting excessive contrast amplification.
* Thresholding: Separates image regions based on pixel intensity using Otsu’s method.
* Canny Edge Detection: Identifies boundaries and intensity changes in images.
* Automated Testing: Uses Pytest to verify algorithm functionality and output properties.
* Image Visualization: Displays original and processed images for comparison.

Installation

1. Clone the repository

git clone https://github.com/DhanushK-27/Medical-Image-Analysis.git
cd Medical-Image-Analysis

2. Create and activate a virtual environment

python3 -m venv venv
source venv/bin/activate

3. Install dependencies

pip install opencv-python numpy matplotlib pytest

Usage

Place a suitable medical image at the path configured in main.py, such as dataset/sample_xray.png.

Run the image-processing pipeline:

python main.py

The program displays the original image and the outputs generated by the implemented algorithms. Processed images are saved in the results/ directory.

Testing

Run automated tests using Pytest:

pytest -v

The tests check basic algorithm functionality, output dimensions, data types, pixel-value ranges, and thresholding behavior.
